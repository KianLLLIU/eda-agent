v2.0.4 改了什么：旧版 .kicad_sch 里 wire=0、junction=0，只有 13 个网络标签贴在引脚上 → KiCad 里看不到连线、文字糊成一团。现在每条网络用「引脚 stub → 垂直支线 → 水平主干」的真实 wire 连通，T 型交点加 junction，主干上只放 1 个 label；Reference/Value 移到符号包围盒外侧；所有模块共用同一 slot 宽度让列网格对齐，竖线统一走列间空隙、不穿过任何元件；未接入网络的引脚自动加 no_connect；纸张按内容自动选 A4/A3。
验证：KiCad 10.0.7 sch export svg / pcb export svg / sch erc 全部 exit 0；ERC 中 multiple_net_names、label_dangling、pin_not_connected 已全部消除。剩余 lib_symbol_mismatch 是自研内联符号库与官方库定义不同导致的无害警告，power_pin_not_driven 是未放置 power 符号的电气提示。
