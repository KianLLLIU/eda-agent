# 硬件需求说明

本文档说明「EDA Agent 智能体」本身运行所需的硬件/软件环境，以及内置示例电路对应的
器件采购需求（由 Agent 自动生成）。

---

## 一、运行 Agent 的环境要求

### 1.1 软件环境（必备）

| 软件 | 版本 | 用途 |
|------|------|------|
| Python | 3.10+ | 后端运行环境 |
| KiCad | 8 / 9 / 10 | 打开、编辑生成的原理图/PCB |
| （可选）LLM API | — | 真实大模型生成，未配置则用离线模板 |

> 打包版（exe）已内置 Python 运行时，无需单独安装 Python，但仍建议安装 KiCad 以查看
> 生成的设计文件。

### 1.2 硬件环境（建议）

| 项目 | 最低 | 推荐 |
|------|------|------|
| CPU | 双核 | 四核 |
| 内存 | 2 GB | 4 GB+ |
| 磁盘 | 500 MB | 1 GB |
| 网络 | 可选（仅 LLM 模式需要） | 宽带 |

## 三、供电要求

- 示例电路供电：**3.3 V / 5 V** 直流，电流 ≤ 100 mA；
- 建议使用稳压电源或 USB 供电，上电前核对极性；
- 更大功率/更高电压的定制电路，需按 Agent 生成的「硬件需求」报告人工复核。

---

## 四、制板与焊接工具（可选）

- KiCad 导出 Gerber 后可送板厂打样；
- 手焊：烙铁 + 焊锡 + 镊子；
- 贴片回流：回流焊机 / 热风枪；
- 调试：万用表、示波器（可选）、逻辑分析仪（可选）。

---

## 五、安全提示

1. 首次上电前核对电源极性，防止短路；
2. AI 生成的电路仅供学习参考，量产或安全关键场景需专业工程师审核；
3. 高电压/大功率电路务必加装保护并谨慎测试。
