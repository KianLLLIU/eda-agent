## 一、工作概述

本次工作完成了「AI Agent 电路板设计」课程大作业的完整交付：一个**自然语言驱动的
KiCad 电路设计智能体**，用户输入一句功能需求，即可自动产出 BOM 清单、引脚级网表、
可打开的 KiCad 原理图与 PCB，并同步生成工作汇报、操作指南、硬件需求三份文档。

同时完成了从「调研 → 设计 → 前后端实现 → 打包部署 → GitHub 开源 → 文档沉淀」的
全生命周期交付，并提供**安装包版**与**网站版**两种形态，支持本地一键部署运行。

## 三、技术亮点

1. **双模式 Agent**：LLM 模式（真实大模型）+ 离线模板模式（无 Key 兜底），自动降级，
   保证「任何环境 5 分钟跑通」。
2. **防幻觉的 Prompt 工程**：符号目录约束 + few-shot + 结构化 JSON + 工程化校验兜底，
   从「源头」和「出口」双向保证 LLM 输出可用。
3. **自研 KiCad 生成器**：吃透 s-expression 文件格式，网络标签连接、模块化布局、
   lib_symbols 内嵌，产出整洁可读、可直接打开的原理图。
4. **单进程部署**：后端同时托管 API 与前端静态资源，一条命令启动，打包简单。

## 四、踩坑与解决（关键经验）

| 问题 | 解决 |
|------|------|
| KiCad 符号坐标系 y 轴方向相反 | 计算引脚世界坐标先翻转 y；统一水平定义规避旋转 |
| power 符号无法用 label 建网 | 电源网络统一用 net label，不实例化 power 符号 |
| 中文工程名兼容性 | 文件名 ASCII 化，标题保留在文件内部 |
| LLM 输出不可信 | extract_json 稳健解析 + validator 兜底 + 失败降级模板 |
| 本机无 KiCad / Bash 环境损坏 | 生成文件用 s-expression 直接写出，脱离 KiCad 可独立生成 |
