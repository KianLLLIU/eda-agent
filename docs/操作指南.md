# 实际操作指南：EDA Agent 本地部署与使用

本指南覆盖「安装 → 配置 → 运行 → 生成电路 → 打开 KiCad」全流程，助教可按此 5 分钟跑通。

---

## 一、安装包版（Windows exe）

### 1.1 下载与运行

1. 下载 `EDA-Agent-Setup` 安装包（或解压版 `dist/eda-agent.exe`）；
2. 双击运行 `eda-agent.exe`；
3. 弹出控制台窗口后，浏览器访问 `http://127.0.0.1:8000`；
4. 若浏览器未自动打开，手动复制控制台打印的地址访问。

> 打包版内置了 Python 运行时与依赖，**无需单独安装 Python**。

### 1.2 查看 API 文档

浏览器访问 `http://127.0.0.1:8000/docs` 可查看交互式接口文档。

---

## 二、网站版（源码 / Docker）

### 2.1 源码方式

```bash
# 前置：Python 3.10+
git clone <仓库地址>
cd eda-agent
pip install -r requirements.txt
python run.py
# 访问 http://127.0.0.1:8000
```

### 2.2 Docker 方式（推荐用于部署）

```bash
docker compose up --build
# 访问 http://localhost:8000
```

## 三、配置 LLM（可选）

**默认开箱即用**：不配置任何密钥时，自动使用**免费在线 LLM**（BlockRun 托管开源模型，无需 key、
无需注册），每个用户打开就能用真实大模型生成电路。三级自动降级：

1. **自定义 LLM**（配置了 key，最灵活）
2. **免费在线 LLM**（默认，无需 key，需能访问外网）
3. **离线模板**（内网等无法访问外网时兜底）

```bash
# 可选：配置自己的 LLM（覆盖免费默认）
# Linux / macOS
export EDA_AGENT_API_KEY="你的密钥"
export EDA_AGENT_BASE_URL="https://api.deepseek.com/v1"   # 或 OpenAI / 通义 / Ollama
export EDA_AGENT_MODEL="deepseek-chat"

# Windows PowerShell
$env:EDA_AGENT_API_KEY="你的密钥"
$env:EDA_AGENT_BASE_URL="https://api.deepseek.com/v1"
$env:EDA_AGENT_MODEL="deepseek-chat"

# 关闭免费 LLM（内网无法访问外网时）
$env:EDA_AGENT_NO_FREE_LLM="1"
```

支持的 LLM 服务（任意 OpenAI 兼容接口均可）：

| 服务 | base_url 示例 | 说明 |
|------|---------------|------|
| **BlockRun（默认免费）** | `https://blockrun.ai/api/v1` | 开源模型，无需 key |
| DeepSeek | `https://api.deepseek.com/v1` | 国内可用，便宜 |
| OpenAI | `https://api.openai.com/v1` | 需科学上网 |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 阿里云 |
| Ollama（本地） | `http://localhost:11434/v1` | 本地模型，免费 |

## 四、生成电路（核心流程）

1. 打开首页，在输入框描述电路，或点击示例标签：
   - 「Arduino 最小系统」
   - 「LED 指示灯」
   - 「5V→3.3V 稳压」
2. 选择生成模式（自动 / 强制 LLM / 离线模板）；
3. 点击「⚡ 生成电路」；
4. 观察上方流水线 5 个步骤依次点亮；
5. 结果区查看 **BOM 清单 / 网表连接 / 工作汇报 / 操作指南 / 硬件需求** 五个标签页；
6. 点击「⬇ 下载 KiCad 工程包」下载 zip。

---

## 五、用 KiCad 打开生成结果

1. 解压下载的 zip；
2. 启动 KiCad 8（或 9/10）；
3. 打开工程文件 `*.kicad_pro`；
4. 双击打开 `*.kicad_sch` 查看原理图；
5. 打开 `*.kicad_pcb` 查看 PCB 并继续布线；
6. 在原理图编辑器运行「检查 → 电气规则检查（ERC）」验证连接。

---

## 六、交互式修正

- **改需求重新生成**：直接修改输入框描述（如「把电容换成 100nF」），重新点击生成；
- **改 JSON 精确控制**：解压 zip 中的 `design.json`，修改后调用 `/api/build` 接口重新生成；
- **改符号库**：编辑 `backend/kicad_gen/symbols.py` 添加新符号，重启服务即生效。

---

## 七、常见问题

| 问题 | 解决 |
|------|------|
| 无法启动，端口占用 | `python run.py --port 8080` 换端口 |
| LLM 调用报错 | 检查 API Key、base_url、网络；或改用离线模板模式 |
| 打开原理图提示缺符号 | 生成器已内嵌 lib_symbols，通常不依赖外部库；如提示缺失，在 KiCad 中重新关联 |
| 下载的 zip 为空 | 检查 `output/` 目录写权限 |
