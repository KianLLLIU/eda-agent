这一版 PCB 是怎么生成的
1. 从本机 KiCad 的 share/kicad/footprints 读取设计里指定的封装（如 Package_DIP:DIP-28_W7.62mm），把整个 .kicad_mod 内联进板子，焊盘、丝印、courtyard、 3D 模型路径全部保留；库里没有就按符号管脚数合成规整封装，没装 KiCad 的机器也能出图。
2. 每个焊盘按网表挂上 (net N "网络名")，所以打开后能看到飞线（连通关系）与网络高亮。
3. 排版用 courtyard 真实尺寸：同一模块内的元件紧挨、模块之间留大间距，一行放不下自动换行， 板框按内容 + 边距自适应并倒圆角，内容在板内居中。
4. 大板（≥70×45 mm）自动在四角加 3.2 mm/M3 安装孔，并把位号隐藏以免压到板边。
说明：自动布线不在本版范围内 —— 元件已摆放到位、网络已连接，走线需要在 KiCad 里完成 （或使用其自动布线插件）。
