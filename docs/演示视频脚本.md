# 演示视频脚本（3–5 分钟）

> 提交物要求：从「输入一句话」到「KiCad 打开原理图」全程真实录屏，可配旁白或字幕。
> 本脚本给出逐秒分镜 + 旁白逐字稿 + 字幕 + 操作步骤，照着录即可。

---

## 一、录制准备

| 项 | 内容 |
|---|---|
| 时长 | 3–5 分钟（建议 3 分半） |
| 工具 | Windows 自带 Xbox Game Bar（`Win+Alt+R`）或 OBS Studio |
| 配音 | 可现场旁白，或录屏后配字幕（本文提供字幕稿） |
| 前置 | 双击 `E:\EDA Agent.exe`，浏览器自动打开 `http://127.0.0.1:8000` |
| 联网 | 建议联网（走免费在线 LLM），离线也能演示（走离线模板） |

---

## 二、分镜脚本（时间轴 + 旁白 + 字幕）

### 第 1 幕 · 开场（0:00 – 0:25）

**画面**：桌面双击 `EDA Agent.exe`，黑窗启动，浏览器自动打开浅色界面。

**旁白 / 字幕**：
> 这是「AI Agent 电路板设计」课程大作业——一个会画板子的 AI。我双击启动它，浏览器自动打开。左边是配置区和智能助手，右边是实时构图舞台。

**操作**：双击 exe → 等浏览器打开 → 指一下左侧「电路难度 / 电路板风格」和「智能助手」。

---

### 第 2 幕 · 选难度与风格（0:25 – 0:45）

**画面**：鼠标点击「挑战」难度，再点「复古暖铜」风格。

**旁白 / 字幕**：
> 先选难度——入门、进阶、挑战，它会通过提示词控制电路的复杂度。再选电路板风格——经典绿、现代极简、复古暖铜，决定构图配色。我选「挑战」和「复古暖铜」。

**操作**：点击「挑战」seg → 点击「复古暖铜」style-opt。

---

### 第 3 幕 · 对话式生成（0:45 – 1:40）

**画面**：在聊天框输入需求，回车，右侧开始实时构图动画。

**旁白 / 字幕**：
> 在对话框输入需求：「帮我设计一块 Arduino 最小系统板，带 16MHz 晶振和 LED 闪烁指示」。发送后，助手提取关键词——主控、晶振、LED、供电——然后开始生成。

**操作**：聊天框输入「帮我设计一块 Arduino 最小系统板，带 16MHz 晶振和 LED 闪烁指示」→ 回车 → 指关键词 chips。

**画面**：上方进度条五步依次点亮；右侧 SVG 舞台上元件逐个出现、连线逐条画出。

**旁白 / 字幕**：
> 看右侧的实时构图——元件一个个摆放到位，连线一条条连起来，整块电路板像被「画」出来一样。这一步是真实的生成过程，不是预先录好的动画。

---

### 第 4 幕 · 查看成果（1:40 – 2:20）

**画面**：构图完成，切换到 BOM / 网表 / 报告标签页。

**旁白 / 字幕**：
> 生成完成。下面可以查看 BOM 清单、网表连接，还有工作汇报、操作指南、硬件需求三份报告。这次挑战难度下，LLM 自动生成了主控、晶振、稳压、去耦、LED 等十多个元件的完整系统。

**操作**：依次点「BOM 清单」「网表连接」「工作汇报」标签页。

---

### 第 5 幕 · 对话式修改（2:20 – 3:00）

**画面**：在聊天框继续输入修改指令，电路实时更新。

**旁白 / 字幕**：
> 重点来了——它可以对话式改图。我直接说：「把 LED 的限流电阻改成 1k，LED 换成绿色」。它理解我的指令，只改这两处，其它不动，然后重新生成。

**操作**：聊天框输入「把 LED 的限流电阻改成 1k，LED 换成绿色」→ 回车 → 看右侧重新构图。

---

### 第 6 幕 · 打开 KiCad（3:00 – 3:30）

**画面**：点「下载 KiCad 工程」，解压，用 KiCad 打开 `.kicad_pro`，展示真实原理图。

**旁白 / 字幕**：
> 最后，下载工程包，用 KiCad 打开——这是真实可编辑的原理图，不是截图。ERC 电气检查也能跑通。

**操作**：点「下载 KiCad 工程」→ 解压 → 打开 KiCad → 打开 `.kicad_pro` → 双击 `.kicad_sch` 展示原理图。（若本机装了 KiCad，也可直接点「用 KiCad 打开」按钮）

---

### 第 7 幕 · 收尾（3:30 – 3:45）

**旁白 / 字幕**：
> 从一句自然语言，到一张可制造的原理图，全链路跑通。谢谢观看。

## 四、录制注意事项

1. **录满全程**：从双击 exe 开始，不要从生成后开始录，体现「输入一句话 → 打开原理图」的完整性。
2. **联网演示**：联网走免费 LLM 效果更「智能」；若担心网络不稳，提前演练一次，确保生成成功。
3. **声音清晰**：用耳机麦录旁白，或录屏后按字幕稿配字幕（更稳）。
4. **时长控制**：控制在 3–5 分钟，太长就砍掉第 4 幕的标签页切换。
5. **避开敏感信息**：录屏时不要出现 API Key、个人账号等。
