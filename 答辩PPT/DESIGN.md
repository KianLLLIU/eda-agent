# DESIGN.md — 学术风设计稿

## 风格定位
学术风（高校答辩）：蓝白浅灰基底，可信、证据驱动、层次清楚，不做营销海报。

## 画布与母版
- 画布 1280×720；安全边距左右 40。
- 页眉 A3 模式：深蓝顶条（`#0E3F8C`）+ 低透明电路线稿，全篇内容页锁定。
- A 页眉 y 0–88（深蓝顶条 + 左侧标题）；B 内容区 y 88–660；D 页脚 y 660–700（左单位灰字 14px，右页码深蓝 14px）。
- 封面/目录/章节扉页/结束页省略 A/D，内容页必须遵守母版。

## 色彩（≤4 主色）
| 角色 | hex | 用途 |
|---|---|---|
| 主蓝 | `#1E4FA8` | 编号、强调、描边 |
| 藏蓝 | `#0E3F8C` | 顶条、章节、深底 |
| 浅蓝 | `#E8EFF8` / `#F0F5FC` | 卡片底、表头浅底 |
| 中蓝 | `#3D7BD9` | 链接、图表第二色 |
| 文本 | `#1A2230` / `#4A5568` / `#8B97A8` | 主/副/辅助 |
| 线框 | `#D6DCE5` / `#E5E7EB` | 描边、表格线 |
| 背景 | `#FFFFFF` / `#F7F9FC` | 主背景 |

配色比：蓝族 35–55%，白底 30–55%，浅蓝 0–35%，红+黄 ≤5%（警示红 `#D9534F` 仅关键词，单页 ≤3%），金色 0。禁紫粉玫红、橙绿大色块、彩虹渐变、纯黑大底。

## 字体（≤2 套）
- 主字体：思源黑体（正文、标题、数字）
- 封面英文长标题：思源宋 / Times（Serif）
- 字号：封面中文主标 60–96 Bold；内容页主标 32–40 Bold；卡内标题 24–30；正文 22–28；表格 18–22；KPI 巨数字 72–120；页脚 14–16。

## 版式与密度
- 内容页 C 区铺满 1200px 宽、≥476px 高；元素不集中在中央 60%。
- 卡片填充率 ≥80%；卡内 padding 上下 16 左右 ≥20。
- 文字对比度 ≥4.5:1；蓝底白字、白底深蓝/深灰。
- 正文页复用 ≥3 类组件（标题条/卡体/流程/编号/数据），≥4 种修辞，≥3 个内容层次。
- 仪式段留白 ≤35%；内容页禁用大留白。

## 组件族
- 编号：深蓝编号方块 / 浅蓝药丸
- 标题条：深蓝标题条（卡顶部）
- 卡体：淡描边卡（白底 + `#D6DCE5` 描边）；深蓝实色卡单页 ≤1、全篇 ≤3、多卡页禁用
- 流程：节点串 / 胶囊步骤 + 箭头
- 数据：KPI 三联数 / 表格高亮

## 页面映射表（强调色分配）
- 封面：藏蓝大底 + 白字，主蓝点缀
- 目录：白底 + 深蓝编号 + 浅蓝卡片
- 章节扉页：藏蓝底 + 大数字 + 白字
- 内容页：白底 + 深蓝标题条 + 浅蓝卡片 + 主蓝编号
- 实验结果（hero）：主蓝大数字 + 白底
- 结束页：藏蓝底 + 白字
